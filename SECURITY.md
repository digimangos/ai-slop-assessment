# Security policy

## Reporting a vulnerability

Please do not disclose vulnerabilities, credentials or sensitive exploit
details in a public issue or pull request.

Use **Report a vulnerability** on the repository's
[Security page](https://github.com/digimangos/ai-slop-assessment/security)
if private vulnerability reporting is available. Otherwise, contact a
maintainer privately using a contact method on their GitHub profile. If no
private contact method is available, open an issue requesting a private
reporting channel without sharing the vulnerability details.

Please include affected versions or commits, a description of the impact and
steps to reproduce. Do not include real credentials or unrelated private data.
Maintainers will review the report and coordinate disclosure with you.

Reports affecting the latest release or current `main` are welcome.
