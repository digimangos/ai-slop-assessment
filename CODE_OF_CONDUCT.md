# Code of conduct

We want this project to be a welcoming place to participate.

Be respectful and constructive. Discuss ideas and code on their merits, assume
good intent, and accept feedback graciously. Harassment, discrimination,
threats, unwanted sexual attention, and publishing someone's private information
without permission are not acceptable.

Maintainers may remove inappropriate content, ask participants to change
their behaviour, or restrict participation when necessary. These expectations
apply in project spaces and when representing the project.

To report a concern, contact a maintainer privately using a contact method on
their GitHub profile. If no private contact method is available, open an issue
asking for a private channel without including sensitive details. Maintainers
will handle reports as discreetly as practical.
